# План реализации

План описывает разработку аналитического кабинета для компаний с несколькими филиалами. Выполняйте шаги по порядку: каждый следующий файл опирается на результаты предыдущих.

## Зафиксированные решения

- Монорепозиторий на `pnpm workspace`.
- Frontend: React, Vite, TypeScript, React Router, TanStack Query, Tailwind CSS, Recharts.
- Backend: NestJS REST API, Prisma, PostgreSQL.
- Авторизация: access JWT и ротируемый refresh token в `httpOnly` cookies.
- Изоляция данных: клиент закреплён за одной компанией; администратор выбирает компанию и видит все компании.
- Внешний источник имитируется отдельным сервисом `provider-mock` в отдельном Docker-контейнере.
- Импорт запускается администратором и является идемпотентным.
- Дневные счётчики и новые отзывы суммируются; рейтинг новых отзывов агрегируется как средневзвешенный по их количеству.
- Полноценный модуль отзывов не реализуется: создаются таблица, миграция и тестовые записи.
- Контракт frontend/backend публикуется через OpenAPI; типизированный клиент генерируется для frontend.
