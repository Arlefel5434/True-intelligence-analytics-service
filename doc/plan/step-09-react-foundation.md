# Шаг 9. Основа React-приложения

## Цель

Создать безопасную основу SPA с маршрутизацией, серверным состоянием и восстановлением сессии.

## Что сделать

1. Настроить React Router с маршрутами login и защищённой области приложения.
2. Подключить TanStack Query и сгенерированный API-клиент с `credentials: include`.
3. Реализовать восстановление текущего пользователя через `/auth/me`.
4. При `401` выполнять один контролируемый refresh и повтор исходного запроса; исключить бесконечные циклы и параллельный шквал refresh-запросов.
5. Создать страницу входа с:
   - валидацией;
   - состоянием отправки;
   - общей ошибкой неверных данных;
   - корректным переходом в кабинет.
6. Реализовать logout и очистку клиентского query cache.
7. Создать лаконичный layout: заголовок, профиль, роль, выход и область контента.
8. Подключить Tailwind CSS и небольшой набор переиспользуемых UI-компонентов без избыточной дизайн-системы.
9. Не хранить JWT в `localStorage`, `sessionStorage` или JavaScript state.

## Критерии готовности

- Неавторизованный пользователь попадает на login.
- Авторизованный пользователь остаётся в сессии после перезагрузки страницы.
- Истёкший access JWT прозрачно обновляется один раз.
- Logout возвращает на login и удаляет защищённые данные из cache.
