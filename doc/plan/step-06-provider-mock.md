# Шаг 6. Имитация внешнего API

## Цель

Создать отдельный HTTP-сервис, реалистично имитирующий источник статистики геосервиса.

## Что сделать

1. Реализовать `provider-mock` как самостоятельное приложение и Docker-сервис без доступа к основной базе.
2. Защитить API фиксированным демонстрационным ключом из environment и не логировать его.
3. Реализовать endpoint статистики с параметрами:
   - `from` и `to`;
   - `page` и `pageSize` либо cursor;
   - при необходимости внешний идентификатор филиала.
4. Возвращать стабильные детерминированные записи:
   - внешний ID записи;
   - внешний ID филиала;
   - дату;
   - просмотры, переходы, звонки, маршруты;
   - среднюю оценку и число новых отзывов за день.
5. Обеспечить одинаковые идентификаторы и значения для повторного запроса того же диапазона.
6. Добавить управляемый сценарий ответа `500` для автоматизированного теста обработки ошибки. Он должен включаться только явным тестовым параметром или настройкой.
7. Валидировать диапазоны дат, пагинацию и API-ключ.
8. Описать контракт через Swagger/OpenAPI.

## Критерии готовности

- Сервис запускается независимо от основного API.
- Основной API обращается к нему по реальному HTTP.
- Повторный запрос возвращает те же внешние идентификаторы.
- Неверный ключ и некорректные параметры обрабатываются предсказуемо.
