# Геоаналитика бизнеса

Контекст описывает доступ клиентов к аналитике присутствия их компаний и филиалов на геосервисах.

## Language

**Компания**:
Организация клиента, объединяющая принадлежащие ей филиалы и ограничивающая область видимости данных.
_Avoid_: Аккаунт, организация, клиент

**Филиал**:
Отдельная точка присутствия, принадлежащая одной компании весь свой жизненный цикл. Смена владельца означает новый филиал без переноса исторических показателей.
_Avoid_: Точка, офис, локация

**Администратор**:
Пользователь с доступом ко всем компаниям и их филиалам.
_Avoid_: Суперпользователь, владелец

**Клиент**:
Пользователь, закреплённый ровно за одной компанией и имеющий доступ только к её данным. У одной компании может быть несколько клиентов.
_Avoid_: Заказчик, аккаунт

**Текущая компания**:
Компания клиента либо явно выбранная администратором компания, ограничивающая доступные в рамках запроса филиалы и показатели.
_Avoid_: Tenant, область доступа, выбранная организация

**Ежедневные показатели**:
Единственный набор аналитических значений одного филиала за одну календарную дату. Количество отзывов означает новые отзывы за этот день, а рейтинг — их среднюю оценку, а не накопительный снимок карточки.
_Avoid_: Статистика, метрики филиала

**Агрегированные показатели**:
Показатели, рассчитанные по доступным филиалам и выбранному периоду: счётчики и новые отзывы суммируются, а рейтинг новых отзывов взвешивается по их количеству.
_Avoid_: Общая статистика, итоговые метрики

**Отзыв**:
Доступная системе отдельная оценка филиала с текстом и датой публикации. Набор доступных отзывов может быть неполным и не обязан совпадать с агрегированным количеством новых отзывов.
_Avoid_: Комментарий, обратная связь

**Внешний источник**:
Имитируемая сторонняя система, предоставляющая ежедневные показатели для импорта.
_Avoid_: Геосервис, провайдер API

**Импорт показателей**:
Получение ежедневных показателей из внешнего источника и их идемпотентное сохранение без дублирования ранее полученных записей.
_Avoid_: Синхронизация, загрузка статистики
